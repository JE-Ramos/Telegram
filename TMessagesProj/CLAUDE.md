# Memories
## ListView in ProfileActivity
The ListView in ProfileActivity contains 27
different view types organized into
sections. Here's a breakdown of the items:

Profile Header Section

- Avatar/Name area (not in ListView -
  overlay)
- Online status
- Bio/About section

Action Buttons Section

- Send Message button
- Call/Video Call buttons
- More options button

User Info Section

- Phone number
- Username (@username)
- Bio/About
- Birthday
- Business hours
- Business location
- Personal channel

Settings Section (for own profile)

- Premium subscription
- Stars balance
- Business account
- Notifications settings
- Privacy settings
- Data settings
- Chat settings
- Stickers & Emoji
- Devices
- Language
- Folder/Filters

Channel/Group Sections

- Subscribers count
- Member requests
- Administrators
- Blocked users
- Channel balance (monetization)
- Join/Leave button

Shared Content Section

- Shared Media (photos, videos, files, etc.)
- Similar channels

Bot-specific Items

- Bot info
- Bot commands
- Bot permissions (location, biometry, emoji
  status)
- Bot stars/TON balance

Debug Section (if enabled)

- Version info
- Debug options
